# Pink Care Impact

create for me a website in react javascript. here's my idea :
my token is called Pink Care Token ($PCAT) a social-impact initiative to combat period poverty — the lack of access to sanitary products and menstrual hygiene education that affects many women and girls, especially in developing countries, often causing them to miss school or work.
How it works
Rather than being pegged to a fiat currency like most stablecoins, PCAT is a redemption-only token pegged to a year's supply of sanitary pads, designed to be used exclusively within the Pink Care Token ecosystem so funds go specifically toward the intended purpose. Once girls receive the token  they can exchange it for sanitary pads from local suppliers
